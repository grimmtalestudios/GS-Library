# GS: Library

Every Grimmtale module depends on this shared library, which Foundry installs for you as a
dependency. You do not need to set anything up. It also lets you choose the colours of Grimmtale
windows and tells the GM when a Grimmtale module has a newer version.

> Foundry v13 minimum, verified on **v13 and v14**. Requires
> [Foundry Virtual Tabletop](https://foundryvtt.com), licensed separately by Foundry Gaming, LLC.

## Features

- The Theme window sets the colours and finish of every Grimmtale Studios module window, and each change applies at
  once. A GM's changes set the world's theme, which everyone sees unless they opt to set and use their own.
- The base colour and accent colour rows each keep and save any custom colours selected, up to ten of each.
- Apply finishes that can be Flat, Glossy, Metallic, Glassy or Translucent. 
- Text colours can be customised for different coloured text for different parts of the module UI, and a
  legibility score automatically rates the set theme from "Hard to read" to "Easy to read".
- Save your custom themes, so you can load it again with one click.
- "Module Update Check" informs the GM about newer versions of the Grimmtale Studios modules in the world when it loads.
- Studio modules take their window styles from the library, so Grimmtale Studios modules share one look and follow the set theme.

## Using it

- In the GS: Library settings, press "Customise theme".
- Click a colour option to use or change it. The + button adds another option to the row for you to use.
- As GM, leave "Use my own theme" unticked to change the world's theme, or tick it to change only yours. 
  A player's changes apply to them alone, and unticking the box takes them back to the world's theme.
- Type a name and press "Save" to keep the current theme. "Back to the studio theme" resets the colours and finish to their defaults.
- When the "Updates waiting" window opens, choose "Remind me later", or "Skip these versions" to stop it showing those versions again.
  
## Compatibility and limitations

- Your own theme and saved themes stay in the browser you made them in, and do not follow you to another browser or computer.
